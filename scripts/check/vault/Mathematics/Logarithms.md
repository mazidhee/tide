# Logarithms

$\log_b x$ answers: what power of $b$ gives $x$? So $\log_2 8 = 3$ because $2^3 = 8$. It's the inverse of [[Exponents]].

Rules: $\log(xy) = \log x + \log y$, $\log(x/y) = \log x - \log y$, $\log(x^k) = k \log x$.

Change of base: $\log_b x = \ln x / \ln b$.

Binary search takes $\log_2 n$ steps because each step halves what's left.
