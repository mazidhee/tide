---
title: Keyboard shortcuts
group: Reference
summary: The ones worth learning first are at the top.
---
| Shortcut | Does |
| --- | --- |
| <kbd>⌘K</kbd> | Search notes, PDFs, saved pages and actions |
| <kbd>⌘↵</kbd> | Submit an answer |
| <kbd>Space</kbd>, <kbd>1</kbd>–<kbd>4</kbd> | Flip and grade a flashcard |
| <kbd>⌘J</kbd> | Toggle the tutor panel |
| <kbd>⌘E</kbd> | Read or edit a note |
| <kbd>⌘N</kbd> | New note |
| <kbd>⌘⇧N</kbd> | New topic |
| <kbd>⌘⇧T</kbd> | Test my thinking |
| <kbd>⌘⇧Q</kbd> | Quiz me on this |
| <kbd>⌘⇧R</kbd> | Review flashcards |
| <kbd>⌘⇧S</kbd> | Save a link |
| <kbd>⌘⇧O</kbd> | Add files |
| <kbd>⌘\</kbd> | Toggle the sidebar |
| <kbd>⌘[</kbd> <kbd>⌘]</kbd> | Back and forward |
| <kbd>Space</kbd> or <kbd>Esc</kbd> | Interrupt the tutor while it's speaking |
| <kbd>Enter</kbd>, <kbd>Tab</kbd>, <kbd>⌥↑</kbd> <kbd>⌥↓</kbd> | Add, indent and move topics in an outline |
