# Data Science Roadmap

Asking questions of data and answering them honestly: probability, statistics, experiments, and clear analysis, with financial data throughout.

## 1. Probability and statistics — CORE

### Probability

- [ ] Random variables, expectation and variance
- [ ] Common distributions: binomial, Poisson, normal, Student's t
- [ ] The law of large numbers and the central limit theorem
- [ ] Monte Carlo simulation
    - _OpenIntro Statistics — Diez, Çetinkaya-Rundel and Barr_

### Inference

- [ ] Sampling distributions and standard errors
- [ ] Confidence intervals and the bootstrap
- [ ] Hypothesis tests and p-values, and their misuse
- [ ] Bayesian updating
    - _OpenIntro Statistics — Diez, Çetinkaya-Rundel and Barr_
    - _Think Bayes — Allen B. Downey_

### Practice

- [ ] Practice: Problem set, bootstrap a confidence interval for a stock's volatility from the lab's prices

## 2. Analysis — CORE

### Working with data

- [ ] pandas: indexing, grouping, joining, reshaping
- [ ] Time series: resampling, rolling windows
- [ ] Missing data and outliers
    - _Python for Data Analysis — Wes McKinney_

### Regression

- [ ] Linear regression and its assumptions
- [ ] Interpreting coefficients
- [ ] Regression for time series: autocorrelation
    - _Forecasting: Principles and Practice — Rob J. Hyndman and George Athanasopoulos_

### Visualisation

- [ ] Choosing a chart for the question
- [ ] Honest axes and uncertainty
    - _Fundamentals of Data Visualization — Claus O. Wilke_

### Practice

- [ ] Practice: Case study, analyse the Treasury yield curve's shape from 2020 to 2025 and explain what it said about the economy

## 3. Causality and experiments — SUPPORTING

### Experiments

- [ ] A/B tests: design, power and analysis
- [ ] Multiple comparisons
    - _Trustworthy Online Controlled Experiments — Kohavi, Tang and Xu_

### Causal inference

- [ ] Confounding and DAGs
- [ ] Difference-in-differences and regression discontinuity
    - _Causal Inference: The Mixtape — Scott Cunningham_

**Capstone Projects**

- [ ] Project: An analysis of a real public dataset that answers a stated question, with uncertainty, a reproducible notebook and a two-page write-up
